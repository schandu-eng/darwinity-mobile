----- BEGIN APP REVIEW NOTES -----
Thank you. Darwinity 1.0.4 (39) is complete and ready for customers.

1) Screen recording
A physical-iPhone recording on the latest iOS is attached to the Resolution Center reply. It starts at launch and shows: email/password sign-in (not Google), home study hub, opening a set, Notes, Flashcards, Quiz, Podcast playback, optional Pro paywall (no purchase), Sign Up, and Settings → Delete account. Please cancel deletion on the demo account; create a new account via Sign Up if you need to test a full delete.

2) Purpose and audience
Personal study app for high-school, college, and adult learners. Students currently rewrite lectures by hand or juggle separate note/flashcard/quiz apps. Darwinity takes one source they were taught from (lecture recording, PDF/slides, or YouTube link) and generates notes, flashcards, quizzes, podcast audio, and exam-prep practice. The free plan is enough to review; Pro is an optional subscription.

3) How to access
Sign-in is required. Use email + password (Google Sign-In is not shown on this iOS build):
Username: [DEMO_EMAIL]
Password: [DEMO_PASSWORD]
This is a free-plan reviewer account with sample notes, flashcards, a quiz, and a podcast already generated.
Path: Launch → Sign In → open a set → Notes / Flashcards / Quizzes / Podcast. Home can Upload PDF, Record audio, or Paste a YouTube URL. Settings → Upgrade shows the optional paywall. Restore Purchases is on Account details. Delete account: Settings → Delete account (or Account details). Do not complete deletion on the demo account.

4) External services
Darwinity API/website (darwinity.com); Apple IAP via RevenueCat (darwinity_pro_monthly, darwinity_pro_yearly); OpenAI; Google Gemini / Vertex AI; Google Cloud Text-to-Speech; YouTube oEmbed/captions; Amazon S3; Mixpanel; Statsig; OneSignal and Resend. Stripe/Razorpay are not used for iOS App Store purchases. Sign in with Apple and Google Sign-In are both offered on this iOS build.

5) Regional differences
Core study features work the same in all regions. Users may set a study language. A 1-day Pro trial is offered in most countries; it is not offered in India (direct-pay intro offer), Pakistan, Sri Lanka, Nepal, or Bangladesh. Subscription prices follow Apple storefronts. No geo-blocked catalog.

6) Regulated / protected material
General education tool, not a licensed school, medical, legal, or financial service. Users upload their own materials for personal use. Operator: darwinity.com. Privacy https://www.darwinity.com/privacy-notice Terms https://www.darwinity.com/terms-of-service Support support@example.com
Not a social network. Uploads are private to the account, so public UGC report/block UI does not apply. Users can delete their materials and their account in-app.

App Store Connect checklist (manual — in order)
----------------------------------------------
PHASE 1 — Listing (no binary yet)

PHASE 2 — First binary
[ ] cd darwinity-mobile
[ ] npm run appstore:preflight
[ ] Confirm EAS secrets include:
      REVENUECAT_IOS_API_KEY (appl_…)
      API_BASE_URL
      SITE_ORIGIN
      (Google iOS Sign-In on; Sign in with Apple enabled via usesAppleSignIn + expo-apple-authentication)
[ ] npm run eas:login
[ ] npm run eas:build:ios
    First run: EAS will ask to create Apple Distribution cert + App Store profile.
    Use the your Apple ID. Complete 2FA on the phone.
[ ] Wait for the build to finish on expo.dev
[ ] npm run eas:submit:ios
    Uploads the .ipa to App Store Connect (TestFlight / this version).
[ ] App Store Connect → Build → select the 1.0.4 build after processing (~5–30 min)
[ ] Encryption question: No

PHASE 3 — Subscriptions (if Pro is in the binary)
