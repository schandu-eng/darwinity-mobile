## Project requirements for this native app (Official Rules §4)

### What to build

- A working software application for **iOS, iPadOS, macOS, or Android**
- Must use the **RevenueCat SDK** to power at least one in-app or web purchase, **or** serve ads through RevenueCat Ads
- Must be capable of installing/running consistently and matching the demo video / description
- US accessibility for testing is required for store categories; **Next Gen is evaluated via video + public repo** (store-download testing exemption)

### Next Gen–specific submission materials

Required on Devpost for Next Gen:

1. **Public open-source code repository URL** (this repo) with all source, assets, and instructions needed to understand/run the Project
2. **Open-source license file** visible / detectable on the repo (MIT here)
3. **Text description** of features and functionality (English, or English translation provided)
4. **Demo video** (< 2 minutes; judges not required to watch beyond 2 min)
   - Shows the Project running on the target device
   - Public on YouTube or Vimeo; link on the Submission form
   - No unlicensed third-party trademarks, copyrighted music, or other restricted material
5. **1024×1024** app icon
6. At least one screenshot **1179×2556** **without** device frames
7. Student / academic email on Devpost

**Not required for Next Gen** (required for other categories):

- Live App Store / Play Store / Galaxy Store URL
- Free trial or judge promo code for IAP unlock
- Paid Apple / Google developer account / store release

### Category-only descriptions

Only include the Next Gen–oriented materials above for this track. Do **not** rely on Grand Prize growth writeups, Influencer likeness, etc., unless also entering those categories under separate eligibility (Minor Entrants / teams with minors cannot).

### Original work / IP

- Submission must be original work, solely owned by the Entrant (or Team/Org), and must not infringe others’ IP, privacy, or publicity rights
- Third-party SDKs/APIs only with authorization / license compliance
- Open source dependencies OK if licenses are respected and the Submission builds meaningfully on them
- No financial/preferential development support from Sponsor/Administrator that would create a conflict (see Official Rules)

### Language

All Submission materials in English, or provide English translations of video, description, testing notes, and other materials.

## Judging criteria — Next Gen (Official Rules §6)

Judges evaluate video + open-source code (no store release required):

1. **Idea** — Clear, useful, interesting, or original? Solves a real problem or creates a compelling experience?
2. **Progress** — Meaningful progress toward a working app? Core functionality clear from video and repo?
3. **RevenueCat use** — Thoughtful use for subscriptions, IAP, web purchases, ads, or another monetization flow?
4. **Craft** — Thoughtful technical choices, product thinking, and care in how the app was built and presented?

Ties: highest score on the first listed criterion, then next, then judge vote if still tied.
